# Lunar Landing Site Navigator

**Team: Astralis.** Lunar Landing Site Navigator is a web-based lunar landing planner for the 2026 NASA Space Apps challenge of the same name. A user chooses a landing time, operating duration, and what matters most to the mission. The navigator ranks the catalog and explains the trade-offs through an inspectable Sun and Earth timeline.

Mission planners are the primary audience. Educators and first-time users should be able to follow the same comparison without prior knowledge of ephemerides. The NASA data, horizon assumptions, and scoring rules must remain visible and reproducible.

The implementation uses a static web app and preprocessing scripts so the public experience can run without live API calls or credentials.
